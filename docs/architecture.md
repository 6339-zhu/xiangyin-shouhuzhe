# 技术架构 · 四层结构

> 箭头为数据流方向；本图为逻辑架构，非精确部署图。

```
┌─────────────────────────────────────────────────────────────┐
│ ① 应用层  用户触达                                            │
│   方言博物馆·数字讲解  |  AI 乡音陪聊(适老)  |  众包采录 APP    │
└──────────────▲──────────────────────────────┬───────────────┘
               │  用户语音请求                 │  回复 + 合成音频
┌──────────────┴──────────────────────────────▼───────────────┐
│ ② 能力层  核心引擎                                            │
│   方言识别 ASR·夹普处理  |  方言理解 LLM 微调                  │
│   方言合成 TTS·韵律建模  |  文化问答 RAG + 知识图谱             │
└──────────────▲──────────────────────────────┬───────────────┘
               │  模型推理/微调与数据回流        │
┌──────────────┴──────────────────────────────▼───────────────┐
│ ③ 模型层  AI 技术栈                                           │
│   低资源语音：迁移学习·半监督                                  │
│   方言大模型：指令微调·RAG 增强                               │
│   端侧轻量化：量化·剪枝·离线                                   │
└──────────────▲──────────────────────────────┬───────────────┘
               │  语料喂入模型训练/主动学习选样本
┌──────────────┴──────────────────────────────▼───────────────┐
│ ④ 数据层  语料底座                                           │
│   田野采录 + 众包语料（老中青三代）                             │
│   转写标注库（方言拼音·发音词典）                               │
│   文化知识图谱（俗语·歌谣·非遗）                                │
└─────────────────────────────────────────────────────────────┘
```

## 模块与代码目录对应

| 架构层 | 代码目录 |
|---|---|
| ① 应用层 | `app/web/`（Streamlit），后续 Vue3 |
| ② 能力层 | `app/api/` + `modules/{asr,tts,llm,rag,knowledge_graph}` |
| ③ 模型层 | `scripts/train_*.py` + `modules/*/` |
| ④ 数据层 | `data/{corpus,transcripts,dictionary,kg}/` |

## 数据飞轮

```
用户录音 → ASR 转写 → 低置信度样本 → 主动学习挑选
   ↑                                    │
   │                                    ▼
众包 APP ← 模型更准 ← LoRA 微调 ← 人工标注回流
```

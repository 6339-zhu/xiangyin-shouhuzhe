# 评测方案

## 一、ASR · 字错误率 CER

- **指标**：CER = (S + D + I) / N，越低越好
- **目标**：基线 ≤ 25%，微调后 ≤ 15%
- **测试集**：留出 5-10 小时萍乡话标注语料，老中青各 1/3
- **基线对照**：
  - 普通话模型直接跑萍乡话（预期 CER 很高）
  - 萍乡话微调后模型
- **工具**：`python-Levenshtein` 或 `jiwer`

```python
# 伪代码
import jiwer
cer = jiwer.cer(reference, hypothesis)
```

## 二、TTS · MOS 自然度

- **指标**：MOS（Mean Opinion Score）1-5 分
- **目标**：合成自然度 ≥ 4.0
- **评测方式**：
  - 邀请 10-20 位母语者盲评
  - 对比：普通话 TTS vs 萍乡话发音词典注入后的 TTS
  - 评分维度：自然度、方言腔调还原、可懂度

## 三、方言对话 · 响应延迟与回答质量

- **指标**：
  - 端到端延迟 < 2s（录音结束 → 合成音频开始播放）
  - 文化知识问答准确率（人工标注 100 题）
- **测试题集**：
  - 纯萍乡话提问（如「恰饭冇？」）
  - 文化知识题（如「安源路矿罢工是哪一年？」）
  - 日常适老问答（如「附近哪里有医院？」）

## 四、知识图谱覆盖度

- **指标**：条目数量 ≥ 5000
- **分类**：俗语 / 歌谣 / 典故 / 非遗 / 美食 / 景点
- **质检**：随机抽 100 条，人工核验准确性

## 五、端侧离线推理

- **指标**：手机端 ASR 单句识别延迟 ≤ 3s（4G/中端机型）
- **模型体积**：量化后 ≤ 500MB
